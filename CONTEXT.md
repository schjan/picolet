# picolet

A GitOps agent that keeps the Podman Quadlet and systemd units on a host in sync with a git repository. It selects, renders and reconciles unit files; it does not model containers.

## Language

### Topology

**Machine**:
One physical or virtual Linux box. A Machine runs one or more Hosts.
_Avoid_: server, node, box

**Host**:
One picolet identity: a `hosts/<name>` entry in the Fleet, served by exactly one Agent under exactly one Linux user. Several Hosts share a Machine when workloads must not share a UID (a trust boundary), or when some must be rootful.
_Avoid_: instance, node, tenant, reconciler

**Agent**:
The running picolet process that reconciles one Host.
_Avoid_: daemon, reconciler, instance

### Fleet

**Fleet**:
The set of everything one git repository describes: shared values, assignments and all Hosts.
_Avoid_: cluster, inventory

**Role**:
The single class a Host belongs to, selecting one group of assignments (e.g. `node`, `node-system`).
_Avoid_: pi_type, type, profile

**Feature**:
An opt-in tag on a Host, each selecting an additional group of assignments; a Host may have many.
_Avoid_: capability, addon, flag

**Service Bundle**:
A directory in the Fleet that groups every file belonging to one logical service, plus optional hook metadata.
_Avoid_: app, stack, application

### Files

**Quadlet**:
A Podman unit file (`.container`, `.network`, `.volume`, `.kube`, `.pod`, ...) that Podman turns into a systemd service. Quadlets are written by the Fleet author, never generated by picolet.
_Avoid_: container spec, service definition

**Raw Unit**:
A hand-written systemd unit (`.service`, `.timer`, `.socket`, `.target`, `.path`) deployed verbatim from the Fleet.
_Avoid_: custom unit, systemd file

**Template**:
Any Fleet file ending in `.tmpl`; rendered before deployment. Files without the suffix are deployed byte-for-byte.

**Managed File**:
A file on the host that picolet wrote and therefore owns; recorded in state and marked on disk.

**Orphan**:
A Managed File or secret found on the host that no longer corresponds to anything in the Fleet.
_Avoid_: stale file, leftover

### Runtime

**Reconciliation**:
One pass that compares the desired files for a Host against what is on disk and applies the difference.
_Avoid_: sync, deploy, apply (apply is one phase of a Reconciliation)

**Hook**:
A reload action (HTTP call, signal or unit restart) triggered when specific secrets, manifests or files change, so a service can pick up changes without a full restart.

**Secret Reference**:
A pointer (`op://…`, `pass://…`) in the Fleet to a value held by a secret provider; the value itself never enters git.
_Avoid_: secret (when the reference, not the value, is meant)
